# Сценарии

## 1. Пустой список заявок

**Дано:** список заявок пуст — ни одного привидения.
**Когда:** оператор запускает автоматическое распределение.
**Тогда:** приложение показывает пустое состояние с понятным сообщением; отчёт показывает
0 размещённых и 0 неразмещённых привидений.

## 2. Привидение, которому не подходит ни одно место

**Дано:** среди заявок есть Кассиан Чердаков — ему нужен чердак, и он не переносит зеркал.
**Когда:** оператор открывает его карточку.
**Тогда:** приложение показывает, что ни одно место не подходит, и объясняет причину для
каждой локации отдельно: Замок отклонён из-за зеркал, остальные восемь — из-за отсутствия
чердака (некоторые — сразу по обеим причинам, если в здании к тому же есть зеркала). Ни одна
причина не повторяет другую дословно для всех мест одинаково — это комбинация двух условий,
а не одно фатальное поле.

## 3. Локация, которую хотят больше привидений, чем она вмещает

**Дано:** и Аграфена Мокрицына, и Полина Сумеречная лучше всего подходят Подвалу типографии
(вместимость 1), причём у Полины итоговый балл там даже выше.
**Когда:** запускается автоматическое распределение.
**Тогда:** место достаётся Аграфене — её дедлайн раньше, а очередь идёт по дедлайну, а не по
баллу. Полина вытесняется на следующий по рейтингу вариант — Заброшенный театр. Это же служит
конкретным примером того, что жадный алгоритм не даёт глобально оптимального результата.

## 4. Конфликт при ручном переназначении

**Дано:** Ефросинья Тихая автоматически размещена в Библиотеке (там тихо).
**Когда:** оператор вручную переназначает её в Подвал типографии, где уровень шума выше её
порога тишины.
**Тогда:** приложение сохраняет новое назначение и показывает предупреждение «Шумно для этого
привидения» — ручное переназначение никогда не блокируется, оно только предупреждает.

## 5. Итоговый отчёт

**Дано:** автоматическое распределение уже выполнено.
**Когда:** оператор открывает вкладку «Отчёт».
**Тогда:** он видит число размещённых и неразмещённых привидений, самые проблемные заявки (по
числу нарушений по всем местам) и перегруженные локации (спрос против вместимости).
